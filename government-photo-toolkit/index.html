What is Government Application Photo Toolkit?

Prepare an application photo with controllable pixel dimensions, DPI, background and target file size.

How to use this tool

  1. Upload the original photo.
  2. Select the required preset or enter custom dimensions.
  3. Set DPI and background according to the application instructions.
  4. Set a target KB only when the application specifies a file-size limit.
  5. Preview and download the processed image.

Important output notes

Always review the downloaded result before submitting it to a website, government portal or application form. Requirements such as dimensions, DPI, file type and maximum file size can vary by the destination.

Frequently Asked Questions

Are application requirements always the same?

No. Requirements can change by recruitment, portal and notification. Always compare the tool settings with the latest official application instructions.

Can I enter custom dimensions?

Yes, the toolkit supports custom pixel dimensions.

Can I target a file size?

Yes, for formats and workflows that support quality-based size reduction; the final byte size can vary slightly.
