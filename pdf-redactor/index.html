Frequently Asked Questions

No. PDFs can contain text, scans, images, fonts, forms and complex layouts, so conversion fidelity can vary.

Should I check the output?

Yes. Always open the downloaded file and verify important text, pages and formatting.

Are files private?

Tools that run locally in the browser do not need to upload the file to a server; check each tool's privacy note for its actual processing method.
