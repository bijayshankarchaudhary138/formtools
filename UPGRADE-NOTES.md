# FormTools Advanced Image Engine Upgrade

This build upgrades the browser-based image workflow with:

- PX, CM, MM and Inch dimensions
- 72/96/150/200/300/600/custom DPI controls
- Aspect-ratio preservation
- Common crop ratios
- Rotate and flip
- JPG, PNG and WebP output
- Quality control
- 20KB/50KB/100KB/200KB/500KB/1MB/custom targets
- Multi-image processing and ZIP download with a browser-side helper
- JPEG/PNG DPI metadata where the output format supports it
- Related image-tool navigation
- New search-intent landing pages for PX/CM/MM/Inch, DPI, crop and format conversion
- Expanded Image Resizer content, privacy explanation and FAQ
- Sitemap updated with new landing pages

All core image transformations are performed in the browser. The optional ZIP helper is loaded only when a multi-file ZIP is requested.
