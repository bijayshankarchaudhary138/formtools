# V19 Exam Keyword Cluster

Added exam-intent pages for NEET UG, JEE Main, UPSC, SSC, Railway RRB and BPSC, plus exact 2026 KB-range pages where current sources provide a strong basis.

Important: exam upload rules are volatile. NEET/JEE current information was cross-checked against current 2026 NTA pages/secondary reports, but the official bulletin/notice remains authoritative. UPSC/SSC/RRB/BPSC pages deliberately avoid inventing one universal KB/dimension rule because those requirements can vary by recruitment/notification.

The pages target natural search intents such as:
- NEET photo size / NEET signature size
- NEET photo 10KB to 200KB
- NEET signature 4KB to 30KB
- JEE Main photo size
- JEE Main photo 10KB to 200KB
- JEE Main signature 10KB to 100KB
- UPSC photo size / UPSC signature size
- SSC photo size / SSC signature size
- Railway RRB photo size / signature size
- BPSC photo size / signature size
