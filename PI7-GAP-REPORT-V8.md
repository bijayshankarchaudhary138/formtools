# FormTools V8 – PI7 gap report

This build was compared against PI7's currently indexed Image and PDF tool lists.

## Added in V8
- Reorder PDF Pages
- Remove Pages from PDF
- Crop PDF
- Sign PDF
- Watermark PDF
- PDF Redactor (rectangle redaction)
- Compare PDF (page/file-size comparison)
- Remove Image Metadata
- Watermark Image
- Favicon Generator
- Image Upscaler
- Image Enhancer
- Social Media Image Resizer
- Photo + Signature Maker
- Bulk Image Resizer
- Image Color Palette Generator

## Still requires dedicated implementation before claiming full PI7 parity
- PDF OCR / searchable OCR
- PDF -> Word
- Word -> PDF
- PDF highlighter with true annotations
- PDF contrast/brightness/saturation editor
- PDF EPUB / EPUB PDF
- PDF Bates numbering
- PDF page-number tool
- PDF unlock/password removal
- PDF image extraction
- Exact-size PDF compressor variants (50KB/100KB/.../10MB)
- AI object removal
- AI background blur / face blur / unblur
- AI photo enhancer / super-resolution
- GIF tools
- HEIC conversion
- Image-to-text OCR
- JPG/PNG-to-text OCR
- PNG crop / circle / square / rounded-corner dedicated pages
- AI face generator / blemish remover / retouch
- DPI checker / exact 200/300/600 DPI pages
- Many country-specific passport/ID pages
- Large set of exact government/social dimension landing pages
- GIF maker/compressor/text-to-GIF
- Audio tools
- Code formatter / online text editor
- Shipping-label crop tools

These are deliberately not represented as "complete" merely by linking to another tool. Each remaining item needs its own implementation and QA.
