What is Government Application Tools?

Use Government Application Tools to complete the task directly in your browser with simple controls and an immediate downloadable result.

How to use this tool

  1. Upload or select your file.
  2. Choose the settings you need.
  3. Run the tool and wait for processing to finish.
  4. Check the result and download it.
