How does this FormTools tool work?

Choose your file, select the options you need, and run the tool. Processing is designed to happen in your browser whenever the feature supports local processing, so your files do not need to be uploaded to a FormTools application server.

Is it free?

Yes. FormTools provides the browser tools without requiring a paid subscription for the standard workflows.

What files are supported?

Supported formats depend on the tool. The upload control on each page lists the accepted formats and the tool shows an error if the file cannot be processed.

What about privacy?

Browser-based tools process files locally where technically possible. Third-party browser libraries or model downloads may be fetched from their published CDNs when a feature requires them; see the Privacy Policy for details.
