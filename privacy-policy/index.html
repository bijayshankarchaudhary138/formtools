Privacy Policy

This policy explains the general way FormTools handles website use and file-processing tools.

Browser-based file processing

For tools that perform processing in the browser, your selected file is processed locally by the page and the resulting file is generated in your browser. Such tools are designed so that the core file transformation does not require uploading the file to a FormTools processing server.

Third-party resources

Some browser tools may load open-source libraries or model assets from third-party content delivery networks. Your browser may request those resources as required by the tool.

Analytics and technical data

Infrastructure and analytics services may process technical information such as requests, browser information, approximate timing and performance data. We do not ask you to enter passwords or sensitive identity information to use ordinary file tools.

Files and downloads

Downloaded results are generated for you by the tool. Keep your own copies of important files and avoid uploading sensitive documents to any online service unless you understand the processing behavior of that particular tool.

Contact

For privacy questions, use Contact FormTools.
