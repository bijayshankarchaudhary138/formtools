# FormTools SEO implementation

This build includes:
- self-referential canonical URLs on indexable pages
- unique page titles/descriptions for priority tools
- robots.txt and sitemap.xml with absolute canonical URLs
- About, Contact, Privacy Policy, Terms, Disclaimer, Cookie Policy and Copyright pages
- tool-specific explanatory content, FAQs and related-tool links for size-target image compression pages
- WebApplication, WebSite, Organization and Breadcrumb structured data where appropriate
- search/utility pages excluded from the sitemap when they are not intended as standalone search landing pages

SEO does not guarantee a #1 ranking. Search engines decide rankings using many signals, including relevance, usefulness, crawlability, competition and external signals.
