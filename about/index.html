About FormTools

FormTools is an online utility platform focused on practical image, PDF, document and application-file tasks. The site is designed to make common file preparation jobs simple on phones and computers.

What FormTools provides

FormTools brings together image compression, resizing, format conversion, PDF utilities, signature and passport-photo preparation, OCR and other browser-based utilities in one place.

Browser-first processing

Where a tool supports browser-side processing, the work is performed in your browser rather than requiring a paid processing API. Exact behavior can vary by tool and browser, so the page for each tool explains its supported workflow.

Our approach

  • Useful tools before unnecessary features.
  • Clear instructions and honest output information.
  • Mobile-friendly interfaces for common application workflows.
  • Search-friendly pages that are also useful to real visitors.
