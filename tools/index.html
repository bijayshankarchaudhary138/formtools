What is All FormTools?

Use All FormTools to complete the task directly in your browser with simple controls and an immediate downloadable result.

How to use this tool

  1. Upload or select your file.
  2. Choose the settings you need.
  3. Run the tool and wait for processing to finish.
  4. Check the result and download it.

Important output notes

Always review the downloaded result before submitting it to a website, government portal or application form. Requirements such as dimensions, DPI, file type and maximum file size can vary by the destination.
