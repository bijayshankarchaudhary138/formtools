# V27 Production Plan
This module is designed as an isolated replacement candidate for the passport workflow.
It provides presets, custom dimensions, DPI, target KB, touch-friendly crop positioning,
zoom/reset, live specifications, single JPG download and related-tool navigation.

IMPORTANT:
- The module is a candidate engine, not a claim that the entire site is already production-integrated.
- Background removal, exact target-byte compression and print-sheet generation require integration with
  the site's existing engines and real-device QA before deployment.
- Do not overwrite the live repository wholesale. Replace the passport route only after QA.
